Where it could go

Reads where the work stands and starts the right workflow. Today the owner reads the checkpoint table and picks.

Skill evals
Fixed case→Skill→Score each step

Run a skill on a known case and check each step happened. Deferred today, since evals cost tokens every run.

Test-driven skills
Missed step→Failing eval→Skill fixed

A step the miner finds skipped becomes an eval that fails first. The skill changes until it passes. Red first, for skills.
