# Product Roadmap

What's next. Each phase is one team ticket. Phase n's ticket file names the
team issue, like `001-my-service-42.md`.

## Now

**Phase 1. CDD checks its own docs.** This repo is its own first team. The
phase outputs scripts that check the docs: each fact in its place, links and
anchors that resolve, and each form under its soft cap. One script runs them
all.
