# skill-evals

**What**

Tests for the skills. Each skill runs in an agent, so its tests are evals.

**Why deferred**

Evals cost tokens on every run. A check that a skill lists its workflow's
steps proves the words and not the work. Deferred by the Product Owner on
2026-11-18.

**Revisit when**

Evals cost less than the bugs they'd catch.
